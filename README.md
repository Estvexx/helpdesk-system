## ⚙️ Compilação

Certifica-te de que tens o `gcc` e o `make` instalados.

Para compilar (só compilar):

```bash
make
```

Para compilar e executar:

```bash
make run
```

Para limpar os ficheiros compilados:

```bash
make clean
```
